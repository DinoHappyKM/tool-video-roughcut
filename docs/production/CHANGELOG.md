# 流程文件變更紀錄

## 0.3.0｜2026-10-04

- 新增 XML 素材自檢與必要轉檔規則，接到 XML 需求即檢查媒體、來源引用與不可轉移功能；只處理必要素材，不全面強制正規化。
- 相容副本必須實際更新時間線，保留剪點、人工構圖、字幕及聲音，再原生匯出並檢查 XML；字幕、動畫與必要處理後音訊另訂交接。
- 多機 A-roll／HDR／透明度／慢動作不套用本批通用 B-roll 的 8-bit 30 fps 歸零方案；保留母檔及來源映射。
- 記錄九支副本、正式短長版來源替換與使用者「測完OK了」的交接回報，不擴張為所有效果、第二批或學生環境均通過。
- 更新技能、工作流程、四張工作表及 T29–T37；新增完整參考資料的跨平台技能包、可重複執行且不覆蓋不同內容的專案安裝方式。
- GitHub 只納入通用規則、匿名化測試結論與部署包，私人素材／工程／完整逐字稿留在本機；既有剪輯引擎與 XML 原型不改。

## 0.2.0｜2026-10-04

- 新增包裝與修改規則主檔及儲存庫 Codex 技能入口；技能引用既有流程，未新增剪輯引擎。
- 納入使用者已確認的繁體字幕與字型、單行畫面置中、B-roll 不加「情境示意」、保留人工修改、片尾先思考文字再美編、非預期入鏡與純人聲比較規則。
- 加入主動自我檢查、修正後重驗與證據紀錄；記錄使用者確認整體流程順利，但不取代逐項品質驗收。
- 區分片頭片尾相同的暫時測試安排與可重用偏好；保留使用者最新手動移除結果，不改時間線或重新匯出。
- 更新需求卡、交付檢查表、首輪狀態與 T19–T28 回歸；原生預覽、實際輸出抽查、完整驗收及學生重現分開記錄。
- 首輪兩部 MP4／字幕已有抽查；最新手動版本輸出、整片聲畫驗收、XML／DaVinci、第二批與工時費用對照仍待完成。
- GitHub 來源更新與靜態驗證不表示 ChatCut 技能庫已安裝、可選取或學生環境已通過。
