# 包裝與修改規則

版本：0.2.0｜更新：2026-10-04｜[製作流程](WORKFLOW.md)

這些是本專案持有人在首輪試跑確認的預設。後續作品沿用；使用者明確指定其他需求時，以該作品需求卡為準。學生可作為起始範例，仍須確認自己的作品規格。

## 接手與修改

先讀目前工程、作用中時間線、需求卡及最新人工修改。保存修改前版本，記錄本次允許變動的範圍。既有片頭片尾、局部放大、切鏡與聲音配置都視為現行內容，不從舊初稿重建或還原。完成後核對未授權變動的軌道與其他作品。使用者已手動移除的內容，不因重新套用樣式而補回。

使用者確認過的偏好不反覆詢問。只在方向衝突、來源不明或會改變已確認內容時釐清必要資訊。回覆說清楚改了哪些，以及哪些只做設定核對、哪些已看過實際畫面。

## 繁體字幕與字型

- 預設繁體中文、單行、畫面水平置中；字幕、片頭片尾、字卡及動畫中的中文都要核對繁體字形。
- 選適合影片氣質且實際涵蓋繁體中文的字型，檢查缺字、替代字型及匯出後字形。首輪使用的 Noto Sans TC 是可用範例，字型不是每種作品都固定相同。
- 置中以整個輸出畫布為基準。文字框內的 center 設定不能替代畫面核對；要檢查框的位置、寬度、視覺中心、裁切與安全範圍。
- 長句先調整文字框並檢查固定換行／逐字稿分組。仍放不下時，按自然語意與實際發聲時間拆成連續的單行字幕；保留完整意思，不刪字、不壓成難讀的小字，也不盲目限制行數而裁掉文字。
- 僅做排版時，保留原文與整句時間範圍；若必須拆句或改變逐字分組，記錄受影響範圍，重驗字幕同步與逐字高亮，不能宣稱所有時間資料都沒變。
- 檢查最長句、最短 cue、片頭後第一句與片尾前最後一句，並核對原生預覽和實際輸出。輸出幀率下沒有落在任何影格的極短 cue，另記為顯示問題，不能用抽圖宣稱已顯示。

## B-roll 與構圖

不自動在 B-roll 上加入「情境示意」、素材分類或其他解釋性標籤。分類和用途保留在素材索引與剪輯決策表；觀眾可見文字須有作品目的或使用者明確需求。首輪使用者已手動移除「情境示意」，下次接手須保留這項修改。

依內容選畫面，通用素材不得被剪成該人物的真實服務成果或當下事件證據；有疑義時換素材或調整敘事，不自動用標籤補救。

逐一檢查 A/B 切鏡及 B-roll 是否有攝影師的手、器材或其他非預期入鏡。可用適當放大與重新構圖處理，但需保留人物、實際操作、服務成果與可讀細節，避免放大過度及切鏡構圖跳動。不要把施作者刻意示範的手當成攝影師的手移除。已由使用者調整的局部放大須保留，實際播放後才判定處理通過。

## 片頭與片尾

先確定文字內容，再做美編。片頭指出這部影片值得看的問題或重點；片尾依內容留下思考、感受或可回答的問題，再接合目的的 CTA。不要只以「謝謝觀看」作為固定片尾文案，也不要加入素材不支持的承諾。

沿用使用者提供的風格參考，檢查文字、字型、色彩、留白與停留時間。首輪「片頭片尾先使用同一張」是暫時測試安排，保留當前手動版本，但不把它變成所有影片的模板。

## 聲音與交付

有沙沙聲時分別比較來源、純人聲、預覽與實際輸出，先排除 BGM 或播放環境造成的混淆。匯出不會自動修好來源噪聲。降噪後核對人聲自然度、金屬感、吃字、音量及銜接；單段噪聲量測只能支持該段，不能替代整片聽感驗收。

每次交付用 [交付檢查表](templates/04_DELIVERY_CHECKLIST.md) 核對人工修改、字幕、B-roll、構圖、片頭片尾與聲音，保存可編輯工程及版本。設定讀回、靜態抽圖、實際輸出抽查、完整播放、使用者驗收與學生環境重現分別記錄。

## 每次交付前的自我檢查

在包裝完成或審片修改後，主動執行下列檢查，不等使用者指出才處理。把結果、證據與待處理項目寫入交付檢查表；不能只有「已檢查」一句話。

1. 逐張核對字幕文字、繁體字形、單行排版、畫布置中及安全範圍；原生畫面與實際輸出重點檢查長句、邊界 cue、特殊字及不同構圖。全片是否無漏字仍依完整播放記錄判定。
2. 比較處理前後的純人聲與實際成片，核對底噪、清晰度、音量、吃字與金屬感。工具可量測或可聽辨的項目先完成；無法確認的整片聽感明列待審，不用量測結果冒充聽感通過。
3. 核對 B-roll 標籤、片頭片尾意圖、非預期入鏡、人工修改保留與其他版本完整性。
4. 不通過的項目在本次已授權範圍內先修正，再重驗受影響字幕、聲畫與輸出；保留修改前後證據。同一問題反覆修正仍不通過，保存版本並報告具體缺口，不以完成通知交付為通過。

## 回饋如何成為規則

每項回饋記錄「問題 → 證據或使用者描述 → 修正／保留事項 → 下次規則 → 驗收 → 適用範圍」。確認的偏好可立即成為預設；工具修復方法只有在重現驗證後才成為操作規範，不將某次底層行為當成所有版本保證。參見 [首輪回饋](pilots/PILOT_001_LESSONS.md) 與 [回歸案例](TEST_CASES.md)。
