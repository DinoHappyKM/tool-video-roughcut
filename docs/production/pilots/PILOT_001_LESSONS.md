## 本輪與下輪的邊界

- 首輪曾輸出 152.1 秒主版本與 59.8 秒短版；已有字幕、B-roll、BGM、人聲處理及片頭片尾，仍在審片。
- 94 張字幕卡的工程資料曾核對；可見影格以原生與輸出抽查驗證。極短 cue 可能不落在任何輸出影格，未以抽圖宣稱每張都可見。
- 使用者最新手動移除標籤的結果以其回報記錄；先前輸出檔需重新匯出才會反映新的人工修改。本次只更新規則，沒有把舊輸出改標為最新成片。
- 保留母版與其他版本的證據，不替代「補回一句／換角度」的完整回歸。第二批素材、長素材、XML／DaVinci 匯入、工時費用對照及學生重現仍待執行。
- 第一批已確認的偏好立即沿用；同類問題若再出現，記錄來源、工具版本、實際畫面與修正工時，再判斷是否需要輔助工具。

## 使用者追加確認

使用者確認本次整體流程順利，要求後續技能主動檢查「兩行改一行、人聲降噪、繁體字幕與適當繁中字型」。已納入規則主檔的交付前自我檢查，發現問題先修正再重驗。這項整體回饋不取代整片音質或所有輸出的逐項驗收，也不表示第二批與學生環境已通過。

## XML 交接的追加成功回報

本批 B-roll 由媒體池可播放、官方 XML 匹配失敗，改為相容副本並換入實際時間線；九段素材及正式短長版均收到使用者匯入成功回報。方法與邊界見 [交接結果](PILOT_001_XML.md)，後續依 [XML 素材自檢與必要轉檔](../XML_HANDOFF_RULES.md) 主動執行；轉檔不能代替字幕、美編與聲音效果交接。

前文「XML 未測、尚未修改最新人工版本」描述的是 0.2.0 整理當時。這次已實際換 B-roll、保留人工欄位並匯出；最後回覆記為交接使用者實測通過，其他無具體證據項目及第二批仍待測。
