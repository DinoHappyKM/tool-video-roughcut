# 兩批真實素材試跑

[入口](../../START_HERE.md)｜所有數字是驗收目標，不是產品承諾。

## 第一批

使用 [PILOT_001](pilots/PILOT_001.md)。選實際多機口播或教學，至少兩個機位；平常使用獨立錄音就一併納入。
素材盡量含重複句、停頓、操作、相機停止後續錄；未包含的測項標待測，不能算通過。
先做一部約 5–10 分鐘主版本及 60 秒主題短片，確認主內容後再做 30 秒與 180 秒版本。素材不適合時回到需求卡調整，不生成不存在的內容湊長度。

## 第二批

使用 [PILOT_002](pilots/PILOT_002.md)。必須是不同真實素材，重做盤點、選題、同步、修改、出片與交接。
保留相同品質基準，記錄是否增加人工介入。第二批不是第一批換個檔名再測。

## 驗收

| 項目 | 通過條件 |
|---|---|
| 分組 | 場次、機位、重拍、分段正確，未知項目已解決或明確排除 |
| 同步 | 前中後及所有重啟處無可見錯位；可量測錨點以一影格內為目標 |
| 內容 | 必留內容完整，沒有斷章取義，各短片獨立成立 |
| 修改 | 換角度及補回一句後重新檢查，其他作品與同步母版保持正確 |
| 包裝 | 繁體字幕與專有名詞正確，操作畫面相符，人聲清楚無明顯爆音／回音 |
| 輸出 | 實際成片播放通過，工程可重開，畫幅與時長符合需求卡 |
| 交接 | XML 實際匯入與媒體連結通過；缺失與重建時間經確認 |

同步量測要記錄幀率和方法。一影格以目標時間線幀率換算；VFR 或來源時基不明時，不輸出偽精確結果。目視檢查不能替代量測數字，量測也不能替代完整播放。

## 時間與成本

以 [試跑報告](templates/05_RUN_REPORT.md) 記錄兩種流程。對照必須採相同來源批次、相同作品範圍與相同品質門檻。
人工投入 = 素材整理＋設定＋操作＋人工審片＋修正＋交接重建；每分鐘只計一次。
被動等待另外記錄；總經過時間另記起訖，等待重疊時不重複相加。
首輪安裝學習時間單列，分別報告含設定與穩定運作的結果。
節省率 = (現行人工投入 − 新流程人工投入) ÷ 現行人工投入 × 100%。
基準缺失、為零或不是同等工作，不計算節省率，也不宣稱省時。

採用門檻：兩批品質通過，兩批各自人工投入減少至少 30%。只有一批通過則尚未確認穩定採用。
費用列幣別、訂閱分攤、AI／生成費、素材費及實際帳單證據；未知不是零元。既有自有音樂／素材優先。

## 失敗與下一步

同步失敗：保存問題與檢查點，人工或 DaVinci 校準後重驗。
內容失敗：回來源補回前提／結論，重驗受影響版本。
交接失敗：明列無法帶過去的項目，完成可接受的重建或留在原工具完成該作品。
沒有連接或素材時，試跑狀態為未執行；文件檢查不算剪輯通過。

## 自建功能投入門檻

同一缺口至少出現在兩批真實素材，且現成設定／工作規範無法解決，再提出：
問題證據、輸入、輸出、品質標準、節省時間、開發與維護代價。
優先素材檢查、跨專案索引、來源追蹤、交接檢查；不預先製作完整剪輯介面、同步引擎或公開 API。
