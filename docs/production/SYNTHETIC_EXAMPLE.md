# 合成示例：同一段話的兩個角度

本頁數字全部為教學合成，沒有真實媒體、沒有做音訊同步；不能列入試跑成績。

## 素材／需求

批次 DEMO；同一場次 SAME_TAKE；A 機 ID ASSET_A，B 機 ID ASSET_B，獨立錄音 ID AUDIO_R。
假定同步母版 30 fps；A 與 R 從母版 0 秒開始，B 從母版 2 秒開始。
作品 OUT_01 要保留母版 10–20 秒的完整句子，放到成片 0–10 秒。

## 決策表填法

| 版本／動作 | 來源 | 來源起訖秒 | 偏移秒 | 母版起訖秒 | 成片起訖秒 |
|---|---|---|---|---|---|
| r1 原角度 | ASSET_A | 10–20 | 0 | 10–20 | 0–10 |
| r2 換角度 | ASSET_B | 8–18 | 2 | 10–20 | 0–10 |
| r1／r2 聲音 | AUDIO_R | 10–20 | 0 | 10–20 | 0–10 |

計算：B 來源 8 秒＋偏移 2 秒＝母版 10 秒，與 A／R 同時。
換鏡時不能把 B 的來源 10–20 秒直接貼上，否則會晚 2 秒。
另一部 OUT_02 即使使用同一來源，也有自己的時間線與需求卡，不跟著 r2 改動。
實機必須另外確認偏移、可用範圍、漂移、嘴型及語意，不能套用本頁假設值。

## 工時示例

現行流程人工投入 120 分鐘；新流程 84 分鐘；(120−84)÷120＝30%。
這不是實測；若第二批人工投入 120→108，僅省 10%，整體仍不達穩定採用門檻。
