# 影片類型與剪輯規則

[入口](../../START_HERE.md)｜以下是選擇策略的規則，不是所有功能已實測的聲明。

| 情境 | 分組／基準 | 主內容判斷 | 特別檢查 |
|---|---|---|---|
| 單機長錄影 → 一部 | 來源完整時間線 | 去錯誤和無效重複，保留整體脈絡 | 句頭句尾、呼吸、意義 |
| 單機長錄影 → 多部 | 共用原始來源，各版本獨立 | 每個主題具前提和結論 | 不從已刪減長版硬拆所有短版 |
| 同場多機 → 一部 | 同步母版＋主音訊 | 內容選取後安排鏡頭 | 嘴型、反應時間、相機重啟 |
| 同場多機 → 多部 | 共用同步母版，各版本獨立 | 每部選題與切鏡可不同 | 修改一部不得波及其他版本 |
| 多次重錄 → 一部 | 按 take 分組 | 選完整且自然的一次 | 不以最後一次或相似台詞決定同步 |
| 口播＋操作錄屏 | 人聲與操作證據對照 | 講到哪個步驟就展示對應操作 | 關鍵點擊、畫面文字與先後順序 |
| 多天、多場活動 | 各場次分別同步 | 依主題或故事重組 | 不捏造時間因果 |
| 多場景微電影 | 場景／鏡次／take／劇本對照 | 表演、資訊揭露、情緒與敘事節奏 | 動作、視線、位置、服裝、道具與聲音連續性 |
| 成片＋補拍 | 原已確認工程另存版本 | 指定替換與補充 | 舊版保留，字幕與配樂重新核對 |
| 沒有共同收音 | 人工可辨識錨點／可驗證時碼 | 先解決同步不確定性 | 未證實前不可列同步通過 |

## 長短版

- 30 秒：聚焦單一重點及必要前提，若有行動邀請需有素材或另行確認。
- 60 秒：一個可獨立理解的主題，保留原因／示範／結果中必要部分。
- 180 秒：可容納完整小教學或較完整故事，不預設等於 60 秒版加長。
- 5–10 分鐘：依內容深度與觀眾需求安排，時長是目標不是強湊理由。
- 橫轉直要重新看臉、操作區、文字與字幕安全區，不只是裁掉兩側。

## 微電影路線

先以一個完整場景做試剪：確認故事意圖 → 檢視各 take → 選表演 → 建立場景敘事 → 檢查連續性 → 人工審片。
通過再擴展到十分鐘作品，預設 DaVinci 精修。不把訪談的「誰說話切誰」直接套用到戲劇。
無對白、刻意停頓與沉默可承載敘事，不能用口播去停頓規則自動移除。
