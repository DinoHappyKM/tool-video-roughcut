# 製作流程

版本：0.2.0｜狀態：testing｜[入口](../../START_HERE.md)

## 0. 先確認目前要處理的工程

確認可用工具、目標 ChatCut／DaVinci 專案、作用中時間線與素材位置。先讀最新工程及人工修改，保存修改前版本，限定本次變動範圍；完成後核對既有封面、局部構圖、其他軌道與版本。僅整理回饋時不改工程。
原始媒體唯讀，代理檔、快取、輸出與紀錄另存。原稿是意圖參考，實際錄音／畫面才是內容證據。

## 1. 盤點與內容地圖

使用 [表 01](templates/01_ASSET_INVENTORY.md)。同時記錄批次、拍攝場次、場景、機位／錄音設備、分段及 take，分開識別：
- 同時多機：同一次事件的不同視角。
- 同機分段：可能連續，也可能停錄，不假定前後無間隙。
- 重拍：相似台詞不代表同一時刻。
- 不同場次：不能直接合成一組同步素材。

檢查聲音、時長、幀率／可變幀率、缺檔與可用內容；逐字稿不清楚的地方標記待聽辨。
依來源時間整理主題、操作與故事段落。不確定的身分與關係保持待確認。

## 2. 討論作品方向

用內容地圖提出 2–3 個有素材支持的方案。使用者已有明確方向則直接沿用，不重問。
可選完整剪輯、指定局部、主題精華、多部作品、長短版或跨素材敘事。
每部填 [表 02](templates/02_OUTPUT_BRIEF.md)，記錄必留／排除內容和時長。第一個確認點是作品方向。

沒有確認方向時可繼續盤點，不先做大幅刪修。原始內容不足以支持需求時說明缺口，不補出未說過的話。

## 3. 同步母版

有同場多機才做同步；單機直接保存未刪修的來源基準。
- 按場次建立完整同步母時間線，各來源獨立標示，選定節目主音訊。
- 記錄同步方法、來源相對同步母版的偏移、信心與前中後段／重啟檢查點。
- 同步和切鏡分開驗收。對齊不表示已選好鏡頭；疊軌也不表示具有 Resolve 原生多機功能。
- ChatCut 路線可保留普通軌道同步母版與衍生成片。自建 Resolve 路線遵守 PR #2 的原生 Multicam 契約，不把另一機當成 B-roll 疊軌冒充。
- 無共同收音、低信心、漂移、VFR 或掉幀列為待處理；人工校準或使用 DaVinci 後仍需重新驗證。不得為消除警告自行變速或修剪原始媒體。
- 相機停錄造成的真實間隙可以存在，不靠強接或假畫面掩蓋。
- 母版鎖定後不做內容刪修；確需修正同步則建立新版母版，將受影響衍生作品標為待重驗。

## 4. 主內容初稿與切鏡

依 [類型規則](SCENARIOS.md)，先選要保留的完整意思，再安排鏡頭。用 [表 03](templates/03_EDIT_DECISIONS.md) 保留來源與理由。
- 口播去除錯誤與無效重複，保留自然呼吸與完整意思。
- 同場反應鏡頭須對應當時真實反應，不能借別的時間偽造。
- 主要聲音連貫；避免所有相機聲音同時播放造成回音。
- 每個成片版本使用獨立時間線，可回來源取回未在長版出現的片段。
- 第二個確認點為主內容初稿。使用者可指定換角度、補回一句、重排內容；不得影響其他已確認版本。
- 未達 30／60／180 秒而內容已完整時，說明取捨；不得用倍速或刪斷句子強湊時長。

## 5. 包裝與精修

主內容確認後加入 B-roll、錄屏、字幕、動畫、BGM 與音效。先讀 [包裝與修改規則](PACKAGING_RULES.md)，將本作品規格寫入需求卡。繁體字幕單行且相對畫面置中；B-roll 預設不加「情境示意」標籤；片頭片尾先確定文字意圖再設計；保留人工修改並檢查非預期入鏡及降噪副作用。
簡單作品可在 ChatCut 完成；微電影與需精修的作品進 DaVinci。交接前決定字幕／動畫／音樂在哪端完成。
預設使用自有且可用素材。缺鏡頭先列補拍、既有素材、敘事調整選項；生成不是默認補救。
上游內容一旦改變，受影響字幕、畫面、音樂及音效全部標為待重驗。已承認的修正不必重問；費用超出先前同意範圍時另確認。

## 6. 交付與保留

第三個確認點為最終成片。用 [表 04](templates/04_DELIVERY_CHECKLIST.md) 檢查實際輸出檔，不能只看完成通知。
保存工程／時間線版本、成片、字幕、素材使用清單、來源範圍、修改紀錄及未解決事項。
轉入 DaVinci 的交接先匯入並播放核對，再將新版本指定為編輯主檔；不宣稱自動雙向同步。
完成兩批 [試跑](PILOT_PROTOCOL.md) 後才判斷採用與自建缺口。

## 確認與狀態

三個主要確認點：作品方向、主內容初稿、最終成片。同步有歧義或重大費用／生成變更時另外處理，不把每次微調變成新批准流程。
狀態用「待確認／進行中／通過／不通過／不適用」，不適用要附理由。
文件支援、靜態檢查、本機實測、使用者驗收與學生重現分開記錄。
