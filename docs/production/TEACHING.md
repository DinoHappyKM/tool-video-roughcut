# 教學交付準備

[入口](../../START_HERE.md)｜狀態：準備規範已建立；學生課堂、macOS 與帳號實測未執行。

## 先後順序

先通過兩批本機試跑，再整理教學。Windows 通過不代表 macOS 通過，老師帳號通過不代表學生帳號通過。
微電影先通過一個場景試剪，再增加十分鐘作品；不把這項能力列成已驗證課程成果。

## 教學包應包含

- 可供教學使用的素材包：至少單機、多機＋錄音，以及對應操作畫面；目前尚未提供。
- 四張共同工作表、試跑報告與帶標示的示例。
- 任務：選題、同步、主內容、換鏡／補句、多版本、聲音字幕與交付。
- 審片表：學生需指出取捨理由、同步檢查點與實際輸出證據。
- 失敗處理：同步無信心、錯誤分組、字幕誤字、聲音重疊、XML 效果缺失、素材離線。
- 工具版本、登入需求、實際費用與免費帳號限制；以當下帳號驗證，不承諾免費完成全部功能。

## 學生選擇哪個 Agent

- 教師先用 Codex 建立可重現範例；已有可用 ChatGPT／Codex 帳號的學生，優先用 Codex。
- 尚無可用 Codex、登入不相容或額度不足者，可改用 ChatCut Agent，另記錄 ChatCut 點數消耗；不預先要求所有學生同時購買兩種訂閱。
- 官方目前列出 Free 等方案可使用 Codex，但免費方案的模型與使用入口有限制，不能據此保證可登入 ChatCut 或支撐完整課程。開課前用實際學生帳號跑一次完整練習。
- 入門課先剪教師提供或學生自有素材，使用已有授權的 BGM／音效。生成影片、音樂、音效列為選修，單獨記錄費用。
- 課程統一使用素材盤點、作品需求、剪輯決策與審片標準；助理選項不同仍交付相同核心成果。
- 兩條路線目前皆未通過學生環境測試；沒有實測數據前，不宣稱哪條一定較便宜或剪得較好。

依據：[ChatCut 點數政策](https://chatcut.io/docs/credits-policy)、[OpenAI Codex 方案與額度](https://learn.chatgpt.com/docs/pricing)，查核日期：2026-10-03。
