## 首輪素材已知限制

- 本機 MCP 未提供 multicam_sync。同步母版採官方 multicam-sync 技能的逐字稿腳本 fallback：28 組相符句、B 偏移 +1.233 秒、confident=true；以 37/30 秒放置普通軌道。這不代表內建同步工具已實測通過。
- 原始收音前中後波形候選偏移 1.242572／1.250447／1.236322 秒；音量包絡候選 1.238333／1.248333／1.238333 秒。各時刻時間映射回讀與靜態畫面支持母版初稿，嘴型與整段播放仍須驗收。
- B 平均 16.223 fps、部分影格間隔達 178.333 毫秒，需播放後挑可用區間；A 平均 25.997 fps。原始媒體保持原位，未自行轉檔。
- 姓名、服務與原理名詞曾有 ASR 誤字，首輪已修正部分；全文正確性仍需審片。A 機主聲音已加人聲處理，完整自然度與聽感仍待驗收，不能由單段量測宣稱整片通過。
- 原片約 3 分半，這批主版建議約 2.5–3 分鐘；原計畫 5–10 分鐘長素材案例仍待後續補測。
- 私人素材盤點、內容地圖、兩版需求卡、剪輯決策、審片單、來源 hash 與量測證據保存在本機成果資料夾；未把原始媒體或逐字稿上傳至本 GitHub 分支。
